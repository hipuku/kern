## What this is

Three independent apps, each its own repository and deployment. Left alone they
would drift: three subtly different buttons, three spacing scales, three
definitions of "muted text". kern exists so that everything a visitor
recognises as *hipuku* is defined **once**.

It is deliberately small. This is not a general-purpose UI kit; it is the
specific set of parts these three experiments actually share, and nothing is
added here speculatively. A pattern earns a place in kern by appearing in more
than one experiment.

## How it is organised

The library follows [Brad Frost's atomic design](https://atomicdesign.bradfrost.com/),
with one direction of dependency: a layer may use the layers below it and never
the ones above.

The last two are departures from the canonical five layers, and both are
deliberate. **Utilities** exists because `ErrorBoundary` renders nothing in the
ordinary case. Atomic design classifies UI, and filing control flow under
"organism" made the word mean two different things. There is no **Pages** layer
because kern has no pages: the experiments are the pages, and they live in their
own repositories.

## What is already decided

These are settled. They are recorded here so that a new experiment does not
re-litigate them.

- **Dark only.** There is no light theme and no plan for one. The void scale
  runs dark-to-light, the opposite of a conventional grey ramp.
- **Tailwind v4 plus CSS custom properties.** No CSS-in-JS, no per-component
  stylesheet. Use `(--var)` parenthesis syntax rather than `[--var]`, since the bracket
  form generates invalid CSS in v4 and is silently dropped.
- **Type is role-based.** You reach for `.type-annotation` because the text is
  an annotation, not because you want 13px. Raw Tailwind size, weight,
  leading and tracking utilities are replaced by the `.type-*` composites.
- **Small caps come from `font-variant-caps`,** applied by `.type-annotation-sc`.
  Never the `uppercase` class.
- **Every experiment picks one accent** as its `--primary`. Components reference
  the semantic role, never a named colour, so retinting is a one-line change.
